# Random DNN generation
The random DNNs in the `data/` directory where generated by
```
python dnn_generator.py
```
and
```
python leaky_dnn_generator
```
Running these scripts will write new random networks to `data/unitary_32_32x3_10_float64.keras` and `data/unitary_leaky_32_32x3_10_float64.keras`. The name and architecture of the networks can be changed by editing the scripts.

# Dual Point Generation
The code in `sign_recovery/` requires precomputed dual points, which the code in `signature_recovery` is capable of producing in a semi-blackbox manner. For simplicity, you can also skip this step by running
```
python dual_generator_whitebox.py cifar10_3x256_64_10_float64
```
and
```
python dual_generator_whitebox.py unitary_32_32x3_10_float64.keras
```
to generate the necessary lists of dual points through entirely whitebox methods. The script will continue to collect dual points indefinitely until killed. Progress will be printed every 100 dual points, and saved every 1,000 dual points. It is recommended to collect at least 10,000 dual points, which should take a few minutes.

# Downloading Dual Points
If you do not want to run the above script, you can also download the precomputed files from the [precomputation-for-hard-label-dnn-extraction](https://github.com/Jchavezsaab/precomputation-for-hard-label-dnn-extraction) repository. These will only be valid if you have not replaced the original random networks.
